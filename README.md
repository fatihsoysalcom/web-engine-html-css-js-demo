# Web Engine HTML CSS JS Demo

This example demonstrates the fundamental components that web rendering engines (like Blink, Gecko, or WebKit) process to create a web page. It uses HTML for structure, CSS for styling, and JavaScript for interactivity. When the button is clicked, JavaScript modifies the page content and style, illustrating how a web engine interprets these changes and efficiently re-renders the visual output for the user.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
